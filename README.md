# Knock-on Lab

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23105637.svg)](https://doi.org/10.5281/zenodo.23105637)

An educational browser game about electron-beam knock-on damage in scanning transmission electron microscopy (STEM). Pick a 2D crystal (graphene, hBN or MoS₂), set up the microscope and find out when the beam knocks an atom out of the lattice.

Available in English, Spanish and Portuguese, with a step-by-step tutorial for first-time players and three interface styles: the game's own console, a TIA-style layout and a Velox-style layout. The TIA- and Velox-style layouts imitate the look of electron-microscope software for teaching; Knock-on Lab is not affiliated with or endorsed by Thermo Fisher Scientific, and TIA and Velox are its trademarks.

**Play:** https://knockonlab.netlify.app

![Knock-on Lab](og-image.jpg)

## For teachers
Runs in any modern browser, on desktop or mobile, with no installation or sign-up.

## Run locally
Open `index.html` in a browser, or serve the folder with
```
python -m http.server 8000
```
and go to http://localhost:8000.
